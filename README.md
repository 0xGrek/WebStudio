# WebStudio

Static HTML/CSS layout practice project.

This repository contains an early multi-page layout exercise with a studio landing page and portfolio page. It is useful as a historical learning artifact rather than a production site.

## Run

Open `index.html` in a browser. The portfolio page is available at `portfolio1/portfolio.html`.

## Status

Early HTML/CSS and Git practice project, refreshed in 2026 with a clearer README for public context.

## Notes

- No build step is required.
- No backend, API keys, or user data are used.
- Some original text/content is preserved from the learning exercise.
